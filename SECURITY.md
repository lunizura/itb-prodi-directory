## Reporting a Vulnerability

The project team and maintainers take security and data accuracy seriously. If you identify a potential security vulnerability within this repository, deployment assets, or automated data ingestion pipelines, please disclose it responsibly.

### Disclosure Protocol
- **Email Contact:** Please submit details via email to `izuki99999@gmail.com` with the subject line `[SECURITY] ITB Prodi Directory - Vulnerability Report`.
- **Include Details:**
  1. Description of the vulnerability or data corruption vector.
  2. Step-by-step instructions or proof-of-concept scripts to reproduce the issue.
  3. Potential impact on downstream consumers or web application integrity.
  4. Any proposed remediations or patches.

### Response Time & SLA
- **Initial Acknowledgment:** Within 48 hours of receipt.
- **Triage & Status Update:** Within 5 business days with assessment findings.
- **Patch Deployment:** Critical security updates will be prioritized and merged directly to the `main` branch.

Please do not open public GitHub issues or discussions for sensitive security vulnerabilities until a fix has been verified and deployed.
